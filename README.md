# StudyIA

A Windows desktop app for spaced-repetition study: multiple-choice quizzes and flashcards,
an explanation when you get one wrong, and automatic scheduling of when each question
comes back. Everything lives in a local SQLite file — nothing leaves your machine, except
when you ask Google Gemini to generate questions.

> The app's interface is in Brazilian Portuguese. The code comments are too.

**No server.** The UI is loaded from disk (`file://`) and talks to Python through the
window's internal bridge. The app opens no listening port (measured with the `.exe` running:
0 listening ports, 0 TCP connections), and the only connection it makes is the Gemini
request when you click *Generate*. That is also why the Windows firewall never prompts.

## Features

- **Quiz and flashcards** with an explanation on every wrong answer.
- **SM-2 scheduling** (Anki-style), one schedule per card.
- **Three ways to add content:** manual entry, import (JSON / CSV / Markdown), or AI generation.
- **Session summary**, free review mode, progress stats and heatmap.
- **Focus mode** (sidebar collapses while studying), light / dark / auto theme, keyboard shortcuts.
- **Two deliverables:** a portable `.exe` and a custom-built installer (no Inno Setup).
- **API key encrypted** with Windows DPAPI; the backup export excludes it.

## Download

Built executables are not stored in the repo. Get them from the **Releases** page, or build
them yourself (below).

| File | What it is |
|---|---|
| `StudyIA.exe` (~34 MB) | Portable. Double-click and it opens; runs from any folder or USB stick. |
| `StudyIA-Instalador.exe` (~44 MB) | Installer: Start Menu shortcut, optional desktop shortcut, entry in *Apps & features*. |

The installer installs to `%LOCALAPPDATA%\Programs\StudyIA` (changeable) **without
administrator rights**. If a version is already installed it becomes "Update" and closes
the running app first. Uninstalling asks whether to also delete your questions and progress;
by default they are kept.

Unattended install / uninstall:

```bash
StudyIA-Instalador.exe --silencioso [--destino <folder>] [--sem-atalho-area]
StudyIA.exe --desinstalar --silencioso [--com-dados]
```

**Requirements:** Windows 10/11 with Microsoft WebView2 (already present on Windows 11 and
most Windows 10). If it is missing, the app says so and opens the download page.

## Build from source

Requires Windows and Python 3.12.

```bash
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# run from source (data goes to .\data)
.venv\Scripts\python.exe desktop.py        # or double-click StudyIA-dev.bat

# build executable\StudyIA.exe and installer\StudyIA-Instalador.exe
powershell -ExecutionPolicy Bypass -File build.ps1
```

`build.ps1 -Apenas programa` or `-Apenas instalador` builds just one. The installer embeds
`StudyIA.exe`, so the program is always built first. Icons and the splash screen are
generated by `tools\make_assets.py`.

## Tests

```bash
.venv\Scripts\python.exe tools\smoke_desktop.py   # 40 checks
.venv\Scripts\python.exe tools\smoke_ia.py        # 18 checks
```

Both drive the **real window** (via `evaluate_js`) against a temporary database.

- `smoke_desktop.py` uses the UI like a user: creates a deck, imports files (including
  Excel's cp1252 CSV), answers wrong, checks feedback and scheduling, keyboard flashcards,
  focus mode, stats, filters, modals, both themes and sidebar navigation. It fails on any
  JavaScript error and confirms the CSP really blocks injected scripts and network calls.
- `smoke_ia.py` tests AI generation against a fake Gemini server (`tools\gemini_falso.py`):
  success, 503/429 (counts requests), unresponsive server, truncated response, oversized
  material. It spends no quota and needs no key.

## How studying works

| Situation | What happens |
|---|---|
| New card | Shows up in the queue immediately |
| Correct | 1 min → 10 min → 1 day → 3 days → ~7 days → … (grows by the ease factor) |
| Wrong | Back in 1 min, interval reset, ease factor drops by 0.20 |
| "Easy" | Skips learning, jumps to 4 days |
| "Hard" | Repeats the current step / grows only 20% |

On a wrong quiz answer the screen shows what you picked, the correct one, the stored
explanation, and when the card returns. The correct answer only reaches the UI *after* you
answer, and a wrong answer is always recorded as a lapse even if the UI sends a different grade.

Shortcuts: `1-9` pick an option, `space` reveals a flashcard, `1-4` grade
(Again / Hard / Good / Easy), `Esc` exits.

**Free review** ignores the schedule and draws random cards from a deck — useful the day
before an exam. Answers still count toward stats and SRS.

## Getting questions in

**1. Manual** — *Questões* tab: statement, options (mark the correct one), explanation, tags.

**2. Import** — *Importar* tab; the format is auto-detected.

Plain text / Markdown:

```
P: How many days does a civil servant have to appeal a disciplinary penalty?
a) 10 days
b) 30 days *
c) 60 days
E: Law 8.112/90 sets 30 days from notification. Don't confuse it with the defense deadline.
T: Law 8.112, disciplinary process
---
P: What is "vacância"?
R: When a public post has no holder.
```

`P:` question (or card front), `R:` flashcard answer, `E:` explanation, `T:` tags,
`*` marks the correct option, `---` separates cards. A block with no options becomes a flashcard.

JSON (Portuguese or English keys):

```json
[{"pergunta": "2 + 2?", "alternativas": ["3", "4"], "resposta": "B", "explicacao": "Simple sum", "tags": "arithmetic"}]
```

CSV with a header — recognized columns: `pergunta`, `a`/`b`/`c`/`d` (or `alternativas`),
`correta`, `explicacao`, `tags`; or `frente`, `verso` for flashcards. In every format the
correct option can be the letter (`B`), a 0-based index (`1`), or the exact option text.

**3. Generate with Gemini** — *Gerar com IA* tab. Paste material (notes, statute text) or
just describe a topic, pick quantity, type and difficulty. Questions appear in a preview;
discard what you don't like, then add the rest to a deck.

You need a Gemini API key: <https://aistudio.google.com/apikey>. Paste it in the app (stored
**encrypted**, see Security) or set `GEMINI_API_KEY` before launching. The default model is
`gemini-3.8-flash` (override with `STUDYIA_MODEL`); the model picker lists what your account
can use.

**Request behavior.** One click = **one** request. The Google SDK by default retries the
whole request up to 4 times on server errors and has no timeout; both were turned off
(measured: a 503/429 went from 4 requests to 1). There is a 2-minute timeout
(`STUDYIA_TIMEOUT_S`), the output-token cap scales with the number of questions (max 20),
and the material is limited to 40,000 characters, with an on-screen counter. If the response
is cut off, the complete questions are kept instead of discarding everything. Errors stay on
the page, with the reason, until the next click.

## Project layout

```
desktop.py            entry point: native window (pywebview + WebView2)
app/bridge.py         UI <-> Python bridge (routes "/api/..." to service.py)
app/service.py        all logic: decks, cards, study, stats, AI
app/srs.py            SM-2 algorithm
app/importer.py       JSON / CSV / Markdown parsers
app/ai.py             question generation via the Gemini API (structured output)
app/db.py             SQLite connection, schema, secure file cleanup
app/cofre.py          API-key encryption (Windows DPAPI)
app/paths.py          where UI and database live (differs when packaged)
app/uninstall.py      uninstaller (the .exe copies itself to TEMP to delete its own folder)
app/winshell.py       shortcuts and the "Apps & features" registry entry
web/                  UI (plain HTML + CSS + JS, no build step)
packaging/            installer source and the end-user LEIA-ME files
assets/               icon and splash (generated by tools\make_assets.py)
tools/                make_assets.py, smoke_desktop.py, smoke_ia.py, gemini_falso.py
build.ps1             builds executable\ and installer\
```

Tables: `deck`, `card`, `schedule` (one per card), `review` (every answer), `session`,
`setting`. All timestamps are stored as UTC ISO-8601.

## Data location

`%LOCALAPPDATA%\StudyIA\studyia.db` for both the portable and the installed app, so
switching between them keeps your history. Set `STUDYIA_DATA` to use another folder.

For backups use **Ajustes → Exportar backup**: a consistent copy of decks, cards and history
**without the API key**. (Copying the `.db` by hand works too; take the `-wal` / `-shm`
files with it if present.)

## Security

Each line was verified by a test, not just read from the code.

| Data | How it's stored | Notes |
|---|---|---|
| **Gemini API key** | Encrypted with Windows **DPAPI**, bound to the user account, with app-specific entropy | Copying the `.db` to another user/machine doesn't carry the key: it shows as "not configured". Never returned to the UI (only configured yes/no). |
| Leftover plaintext key | **Wiped from the file** on migrate / change / remove | SQLite doesn't overwrite old data; it lingers in free pages and the WAL. The app uses `secure_delete` and runs `VACUUM` on those changes (a real bug that was found and fixed). |
| Exported backup | Contains no key, not even encrypted | |
| Error messages | Anything key-shaped is redacted | |
| Questions and progress | **Not encrypted** | Live in `%LOCALAPPDATA%` (readable only by you and admins). Use BitLocker if that matters. |
| UI pages | Strict CSP: only the app's own scripts/styles, **no network** from the page | Tested to block injected scripts and external `fetch`. All user/AI text goes through `esc()` before becoming HTML. |
| Links | Only `https://aistudio.google.com/` opens in the browser | |
| Uninstaller | Removes **only** `StudyIA.exe` and `LEIA-ME.txt` (and the folder if empty) | It used to delete the whole folder; installing into "Documents" would have wiped them. Fixed. |

**Honest limits.** DPAPI protects data *at rest*: any program running as the **same user**
can ask Windows to decrypt it (the same model as Chrome's saved passwords). And text you send
for generation goes to Google; on the free Gemini tier Google may use it to improve its
products — check their terms and don't paste personal or confidential data.

## Known limitations

- **SmartScreen warning.** The executables are not code-signed, so on first run Windows shows
  "Windows protected your PC" (*More info → Run anyway*). Only a paid code-signing
  certificate removes it. Windows Defender does not flag anything.
- Questions and progress are not encrypted (only the API key is).
- Windows only.
